# MAVULA Brand Usage

MAVULA is infrastructure for the next generation of finance.

Primary domain: `mavula.io`

Developer and open source domain: `mavula.dev`

The organization profile should use `mavula_branding.png` as the primary visual
asset and keep badges limited to useful project metadata: license, build,
contracts, Node, TypeScript, Go, Java, COBOL, PostgreSQL, Redis and Kubernetes.

Do not add decorative badges, speculative claims or unused technology logos.

The brand image may be used in official MAVULA repositories and documentation.
External use requires written permission unless it is nominative fair use.
