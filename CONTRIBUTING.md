# Contributing to MAVULA

MAVULA accepts contributions through pull requests.

## Requirements

- Use a focused branch and a pull request.
- Keep changes scoped to one module or one contract boundary.
- Add or update tests when behavior changes.
- Run the relevant validation commands before requesting review.
- Do not commit secrets, private customer data or `.env` files.

## Licensing

By contributing, you agree that your contribution may be distributed under the
license of the target package. MAVULA may require a Contributor License
Agreement before merging non-trivial contributions.

## Governance

Maintainers decide roadmap, release eligibility, security handling and final
acceptance. Technical discussion should use short, concrete language and cite
the affected module, contract or runtime behavior.
