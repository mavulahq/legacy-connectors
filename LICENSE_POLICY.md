# MAVULA Licensing Policy

MAVULA follows an open core model.

## Open Source Core

The implemented financial runtime packages are open source:

- `packages/ledger-core`: AGPL-3.0-only
- `packages/workbench`: AGPL-3.0-only
- `packages/settlements`: AGPL-3.0-only
- root contracts, scripts and documentation: AGPL-3.0-only unless a file states otherwise

Network use of AGPL-covered services must comply with AGPL-3.0-only source
availability obligations.

## Operations Tooling

`packages/operations` is Apache-2.0 to allow broad use of local development,
deployment and infrastructure tooling.

## Reserved Commercial Scope

Enterprise hosting, managed operations, proprietary provider integrations,
compliance packs, private modules, branding assets and commercial support may
be licensed separately. Source-available or commercial files must state their
license explicitly.

## Marks

Code licenses do not grant rights to the MAVULA name, logo, domains or product
marks. See `TRADEMARKS.md` and `BRAND.md`.

## Legal Review

This repository records the intended policy. Final publication should be
reviewed by qualified counsel before a public launch or relicensing campaign.
